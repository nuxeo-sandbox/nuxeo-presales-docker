# Agent instructions

* Documentation lives in the GitHub Wiki
  (https://github.com/nuxeo-sandbox/nuxeo-presales-docker/wiki), which is a
  separate git repo (nuxeo-presales-docker.wiki).
* README.md contains only: what the project is, requirements, the bootstrap
  command, support, and license. Do not add options, examples, troubleshooting,
  feature notes, or explanations to it.
* If asked to put such content in README.md, decline, cite this rule, and
  propose the Wiki page where it belongs instead.
* When a change alters behavior, name the Wiki page that needs updating. If
  you cannot edit the Wiki, tell the user which page to update.
